# Persia at War — playtest build

An educational draft-and-battle game about real battles from Iranian history,
for ages 9 to 14. This repository holds **only the built game**, so that it can
be put online for playtesting and art review. The source lives elsewhere and is
private.

**Play it:** the link is on the repository's Pages settings, or in the most
recent run under Actions.

## What works here

Everything except playing another person: the Chronicle campaign, the card
collection and codex, all thirteen arenas, and battles against the computer.
Online play needs a server that stays alive, which a static site is not.

## Leaving notes

There is a pencil button in the corner of every screen. Tap it, choose
**bug / idea / confusing**, and write a line. The note is saved with the screen,
the arena, the trophy count, the build and the screen size attached, so nobody
has to describe where they were.

**Export** turns everything you have written into one Markdown file to send
back. Nothing is transmitted anywhere and there is no account: notes stay in
your own browser until you export them.

## What is deliberately unfinished

Most of the art. Two of thirteen arenas are painted, one of ten commander
portraits, and the spell cards have no art at all — where a picture is missing
you will see a placeholder shape rather than a gap. The history is sourced and
every card says what is attested and what is disputed; the art is not there yet.
